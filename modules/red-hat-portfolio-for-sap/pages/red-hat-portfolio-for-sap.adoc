#  Red Hat Portfolio for SAP

= Red Hat Portfolio for SAP

The Red Hat portfolio provides an automated, end-to-end open hybrid cloud infrastructure designed to support SAP and non-SAP workloads across on-premises and cloud environments. It enables organizations to standardize their SAP S/4HANA deployments on a reliable platform.

Key components of the portfolio include:

* **RHEL for SAP Solutions:** A bundled subscription including the base OS, High Availability Add-on, Smart Management, and Red Hat Insights for proactive risk mitigation.
* **Automation and Lifecycle:** Utilizes RHEL System Roles for SAP and Red Hat Ansible Automation Platform to automate migrations, deployments, and day-2 operations.
* **SAP-Specific Optimization:** Includes specialized configurations, libraries, and update services that provide extended support for specific minor RHEL releases to ensure stability for SAP environments.
